# Gallery Images

Place gallery images in this folder for the gallery grid slideshow.

**Recommended specifications:**
- Format: JPG, PNG, or WebP
- Resolution: 800x800 or higher (square aspect ratio)
- Aspect ratio: 1:1 (square)
- File names: gallery1.jpg through gallery24.jpg

The gallery displays 8 images at a time in a 2 rows × 4 columns grid layout.
The entire grid changes every 10 seconds automatically.
You can add more pages by adding sets of 8 images.
