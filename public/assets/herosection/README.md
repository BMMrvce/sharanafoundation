# Hero Section Images

Place hero background images in this folder for the slideshow on the homepage.

**Recommended specifications:**
- Format: JPG, PNG, or WebP
- Resolution: 1920x1080 or higher
- Aspect ratio: 16:9
- File names: hero1.jpg, hero2.jpg, hero3.jpg, etc.

**Current images needed:**
- hero1.jpg
- hero2.jpg
- hero3.jpg

The hero section will automatically cycle through these images every 5 seconds.
